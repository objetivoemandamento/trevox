# TREVOX

Pré-vestibular online para ENEM e vestibulares tradicionais.

## Executar

Abra `index.html` no navegador. O projeto atual é um protótipo estático responsivo; formulários, simulados e redação possuem funções demonstrativas no navegador.

## Publicação na Vercel

Importe este repositório na Vercel. Como é um site estático, não exige comando de build nem diretório de saída: a raiz do repositório contém o `index.html`.

## Próximas integrações

- Supabase Auth e banco de dados para contas e progresso persistente.
- Hospedagem de vídeo para aulas.
- Gateway de pagamento para matrículas reais.
- Produção e revisão pedagógica do conteúdo curricular.

**Nota:** pagamentos e autenticação reais ainda não estão conectados. Questões e materiais atuais são demonstrativos.
